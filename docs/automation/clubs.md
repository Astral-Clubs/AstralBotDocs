# События клуба

<p class="lead">Сценарий может сработать, когда игрок вступил в клуб или покинул его. Бот знает об игроке ник, число кубков и то, привязан ли его тег к аккаунту Telegram.</p>

## Какие события есть { #events }

| Событие | Когда срабатывает |
|---|---|
| Игрок вступил в клуб | В клубе появился новый игрок |
| Игрок покинул клуб | Игрок вышел из клуба или был исключен |

Привязывать клуб к чату не нужно: клубы выбираются прямо в сценарии. Состав клубов проверяется раз в 2 минуты, а бот забирает новые события каждые 30 секунд, поэтому сообщение приходит с небольшой задержкой.

## Выбор клубов { #clubs }

В настройках блока **«Когда»** откройте список **«Клубы»** и выберите один или несколько клубов из тех, что добавлены в Astral. Если не выбрано ничего, сценарий реагирует на события всех клубов.

## Данные игрока { #data }

В тексте сообщения доступны данные игрока из пространства [astral](../templates/astral). Условия **«Кубки игрока»** и **«Привязан тег Telegram»** позволяют по-разному реагировать на игроков, например поздороваться только с теми, у кого тег уже привязан.

## Пример { #example }

Сценарий приветствия новых игроков:

1. **Когда:** Игрок вступил в клуб.
2. **Если:** Привязан тег Telegram.
3. Ветка «Нет»: **То:** отправить сообщение «Привяжите тег в боте, чтобы получить роль».
4. Ветка «Да»: **То:** изменить роли и выдать роль участника клуба.
