# События, условия и действия

<p class="lead">Справочник блоков сценария. Названия совпадают с теми, что показаны в панели.</p>

## События { #events }

| Раздел | События |
|---|---|
| Участники | Участник вошел, Участник вышел, Заявка на вступление, Заявка одобрена, Заявка отклонена, Участник сменил имя, Закончился режим новичка, Капча пройдена, Капча провалена |
| Уровни | Новый уровень |
| Модерация | Выдано предупреждение, Снято предупреждение, Выдан мут, Снят мут, Выдан бан, Снят бан, Участник исключен, Наказание истекло, Сработала лесенка |
| Роли и права | Изменились роли, Назначен администратор, Администратор разжалован, Изменены права администратора |
| Сообщения | Новое сообщение, Сообщение изменено, Бот удалил сообщение, Сообщение закреплено |
| Автомодерация | Сработала автомодерация |
| Чат | Изменено название чата, Изменено фото чата, Создан топик, Изменен топик, Закрыт топик, Начат видеочат, Добавлен буст |
| По расписанию | Каждый день, Каждую неделю, Через равные промежутки |
| Клубы | Игрок вступил в клуб, Игрок покинул клуб |

Для событий с участником можно ограничить сценарий ролями бота и топиком, а также пропускать ботов. Расписание задается временем суток, днем недели или интервалом не реже раза в 5 минут.

## Условия { #conditions }

| Условие | Что проверяет |
|---|---|
| Дней в чате | Сколько дней участник состоит в чате по данным бота |
| Роль участника | Есть или нет роль бота |
| Уровень | Уровень участника |
| Предупреждения | Количество действующих предупреждений |
| Администратор | Является ли участник администратором |
| Новичок | Находится ли участник в режиме новичка |
| Сообщение со ссылкой | Есть ли в сообщении ссылка |
| Текст сообщения | Содержит ли сообщение заданный текст |
| Привязан тег Telegram | Только для событий клуба: связан ли игрок с аккаунтом Telegram |
| Кубки игрока | Только для событий клуба: число кубков |
| Своя формула | Выражение на языке [шаблонов](../templates/advanced/expressions) с результатом «истина» или «ложь» |

Условия про участника недоступны для событий без участника, например для расписания.

## Действия { #actions }

| Действие | Что делает |
|---|---|
| Отправить сообщение | В чат, в топик, в личные сообщения или в чат логов. Можно удалить сообщение через заданное время |
| Изменить роли | Выдает и снимает роли бота, выдачу можно ограничить сроком |
| Наказать | Предупреждение, снятие предупреждения, мут, бан, снятие мута и бана, исключение |
| Удалить сообщения | Сообщение из события или последние сообщения участника |
| Начислить опыт | Добавляет или забирает опыт |
| Ограничить права | Отнимает выбранные права участника в Telegram, можно на срок |
| Выдать тег | Тег участника в списке чата, до 16 символов |
| Закрепить сообщение | Сообщение из события или новое |
| Записать атрибут | Сохраняет свою метку участника, которую видят условия и шаблоны |
| Подождать | Пауза перед следующим шагом. Пауза переживает перезапуск бота |

Действие, которому нужен участник или сообщение, недоступно для события, где их нет. Панель показывает это в списке блоков.

## Шаблоны { #templates }

В разделе есть готовые сценарии: **«Приветствие новичка»**, **«Фильтр ссылок»**, **«Награда за уровень»**, **«Итог дня»**, **«Мут за предупреждения»**. После создания их можно менять как обычные сценарии.
