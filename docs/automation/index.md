# Автоматизация

<p class="lead">Сценарий описывает, что бот делает сам: «когда» произошло событие, «если» выполняется условие, «то» бот выполняет действия. Настраивается в панели, в разделе **«Автоматизация»**, код писать не нужно.</p>

## Из чего состоит сценарий { #structure }

| Блок | Что делает | Пример |
|---|---|---|
| **Когда** | Событие, с которого начинается сценарий. Он всегда один | Участник вошел в чат |
| **Если** | Проверка с ответами «Да» и «Нет». Вложенность блоков «Если» не больше двух | Участник в чате меньше двух дней |
| **То** | Действие бота. Действий можно ставить сколько нужно, в пределах общего лимита блоков | Отправить приветствие |

Сценарий читается сверху вниз. Если в блоке «Если» нет шага для одной из веток, сценарий в этой ветке просто заканчивается.

## Как создать сценарий { #create }

1. Откройте в панели раздел **«Автоматизация»**.
2. Нажмите **«Создать сценарий»** или выберите готовый шаблон ниже списка.
3. Нажмите на блок **«Когда»** и выберите событие.
4. Нажмите **«+»** под блоком, чтобы добавить условие или действие. Нажатие на блок открывает его настройки.
5. Нажмите **«Сохранить»**, затем включите сценарий переключателем.

Пока в сценарии есть ошибки, включить его нельзя. Проблемные блоки подсвечены, причина написана на самом блоке.

## Проверка перед включением { #test }

На странице сценария есть блок **«Проверка сценария»**. Бот проиграет сценарий на тестовых данных и покажет, какие действия выполнил бы. Ничего при этом не отправляется и не меняется. Проверка доступна для сохраненного сценария.

## Ограничения { #limits }

| Что | Предел |
|---|---|
| Сценариев в одном чате | 50 |
| Блоков в сценарии, считая «Когда» | 20 |
| Вложенность блоков «Если» | 2 |
| Пауза в блоке «Подождать» | до 7 дней |
| Запусков одного сценария в минуту | от 1 до 600, по умолчанию 30 |

Если сценарий срабатывает чаще лимита, лишние события пропускаются и попадают в историю со статусом **«Пропущен»**.

::: warning Внимание
Сценарий не запускается от действий другого сценария, чтобы они не зацикливались. Разрешить это можно в **«Настройках»** сценария, но делать это нужно осторожно.
:::

## История запусков { #history }

На вкладке **«История»** видно, когда сценарий срабатывал, чем закончился запуск и сколько занял. Ошибка выполнения показывается в строке запуска. Последняя ошибка также видна в списке сценариев.
