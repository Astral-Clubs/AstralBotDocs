# Словарик

<p class="lead">Простые объяснения слов, которые встречаются в документации.</p>

| Слово | Что значит |
|---|---|
| **Шаблон** | Текст сообщения с пометками, куда бот подставит данные |
| **Шаблонный движок** | Часть бота, которая читает шаблон и собирает из него готовое сообщение |
| **Островок кода** | Вставка в шаблоне в скобках `{{ }}`, `{% %}` или `{# #}` |
| **Переменная** | Имя, под которым хранится значение: `member`, `chat`, или свое, созданное через `set` |
| **Свойство** | Часть значения, которую берут через точку: у `member` есть `name`, у `chat` — `title` |
| **Метод** | Действие, которое можно выполнить над значением: `member.getAttribute('coins')` |
| **Функция** | Готовая операция: `upper('текст')`, `random(1, 6)` |
| **Аргумент** | То, что передается в функцию в скобках, или слово после команды в чате |
| **Выражение** | Все, что вычисляется в значение: `2 + 2`, `member.rank.level >= 10` |
| **Тег** | Команда для бота внутри `{% %}`: `if`, `for`, `set` |
| **Условие** | Проверка «если… то…» — тег `if` |
| **Цикл** | Повторение куска шаблона для каждого элемента списка — тег `for` |
| **Макрос** | Своя функция, объявленная в шаблоне |
| **Строка** | Текст в кавычках: `'привет'` |
| **Список** | Несколько значений по порядку: `[1, 2, 3]` |
| **Карта** | Пары «ключ → значение»: `{ vip: 500 }` |
| **Undefined** | «Ничего нет»: так выглядит значение несуществующей переменной или свойства |
| **Pipe** | Вертикальная черта `\|`: передает значение в функцию — `name \| upper` |
| **Экранирование** | Защита символов разметки: чтобы `*` в имени не превратилась в курсив |
| **Rich-сообщение** | Новый формат сообщений Telegram с заголовками, таблицами и блоками |
| **Markdown** | Разметка значками: `**жирный**`, `# заголовок` |
| **Пользовательская команда** | Команда, которую вы создали сами в панели |
| **Действие** | Шаг команды: отправить сообщение, задать вопросы, выдать роль |
| **UUID** | Уникальный идентификатор действия, по которому на него ссылаются кнопки и `run` |
| **Алиас** | Другое название команды для вызова с префиксом: `!кубик` |
| **Префикс** | Символ перед командой: `!` или `.` |
| **Кулдаун** | Пауза, в течение которой команду нельзя вызвать повторно |
| **Эфемерное сообщение** | Сообщение, которое видит только один участник |
| **Атрибут** | Значение, которое бот запоминает надолго для участника или чата |
| **Индекс** | Отсортированная таблица «ключ → число» для топов |
| **Параметры** | Временные данные, которые передаются от команды к кнопкам и между действиями |
| **Общий шаблон** | Кусок шаблона, который подключается в другие шаблоны по имени |
| **Квота** | Ограничение на одно выполнение шаблона: сколько шагов, обращений, отправок |
| **Роль бота** | Роль, созданная в панели бота |
| **Топик** | Тема в чате-форуме Telegram |
| **Кейс** | Запись о наказании с номером |
| **Лог-чат** | Чат или канал, куда бот пишет журнал событий |
