# Form

<p class="lead">Ответы на вопросы <a href="/commands/actions/form">формы</a>. Доступны как <code>form</code> в действии, которое запускается после отправки формы.</p>

## Свойства { #properties }

| Свойство | Тип | Описание |
|---|---|---|
| `values` | Карта | Ответы: ключ — ID поля формы, значение — ответ участника |

| Тип поля | Что лежит в `values` |
|---|---|
| Текст | Строка |
| Число | Число |
| Выбор | Значение выбранного варианта |
| Да/Нет | `true` или `false` |

## Пример { #example }

```template
Заявка от {{ member }}:
- Тег: {{ form.values.tag | upper }}
- Кубки: {{ form.values.trophies | number_format }}
- Готов к клубной лиге: {{ form.values.active ? 'да' : 'нет' }}
```
