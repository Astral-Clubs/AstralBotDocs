# Rank

<p class="lead">Уровень и опыт участника в модуле «Уровни». Доступен как <code>member.rank</code>.</p>

Опыт до следующего уровня считается по формуле: `5 × L² + 50 × L + 100`, где L — текущий уровень. Максимальный уровень — 999.

## Свойства { #properties }

| Свойство | Тип | Описание |
|---|---|---|
| `level` | Число | Текущий уровень |
| `totalExp` | Число | Весь опыт участника |
| `levelExp` | Число | Сколько опыта нужно на текущем уровне целиком |
| `levelCurrentExp` | Число | Сколько опыта набрано на текущем уровне |
| `remainingExp` | Число | Сколько осталось до следующего уровня |
| `rank` | Число | Место в рейтинге чата |
| `cookies` | Число | Сколько «печенек» участнику подарили |
| `voiceActivity`, `voiceActivityMs` | — | Всегда пусто: бот не видит голосовые чаты |

## Пример: полоска прогресса { #example }

```template
{% set r = member.rank %}
{% set filled = round(r.levelCurrentExp / r.levelExp * 10, 'FLOOR') %}
Уровень {{ r.level }} · #{{ r.rank }} в чате
{% for i in [1..10] %}{{ i <= filled ? '🟦' : '⬜' }}{% endfor %}
{{ r.levelCurrentExp }} / {{ r.levelExp }} XP
```
