# Event

<p class="lead">Данные события, из-за которого бот отправляет сообщение. Доступны как <code>event</code>. Набор полей зависит от места шаблона — см. <a href="/templates/places">Где используются шаблоны</a>.</p>

У любого события есть `event.type` — тип события.

## Приветствие { #welcome }

| Поле | Тип | Описание |
|---|---|---|
| `inviteLinkName` | Строка | Название ссылки-приглашения, по которой пришел участник |
| `viaJoinRequest` | Логический | Участник вступил через заявку |

## Приветствие при наплыве { #aggregated }

| Поле | Тип | Описание |
|---|---|---|
| `members` | Список [Member](./member) | Кто вступил |
| `count` | Число | Сколько вступило |

## Капча { #captcha }

| Поле | Тип | Описание |
|---|---|---|
| `type` | Строка | Вид проверки: кнопка, эмодзи или пример |
| `timeoutSeconds` | Число | Сколько секунд дается на ответ |

## Уведомление наказанному { #punishment }

| Поле | Тип | Описание |
|---|---|---|
| `type` | Строка | Тип наказания |
| `reason` | Строка | Причина |
| `duration` | — | Срок наказания |
| `caseNo` | Число | Номер кейса |
| `appeal` | Строка | Как обжаловать |

## Лог-чат { #logs }

Шаблон события в лог-чате. Поля перечислены в [Логи в лог-чате](/templates/logs#template).

| Поле | Тип | Описание |
|---|---|---|
| `type` | Строка | Тип события, например `mod.ban` |
| `actor` | [Member](./member) или строка | Кто сделал. Если действие совершила система, строка с названием источника |
| `target` | [Member](./member) | С кем сделали |
| `data` | Словарь | Подробности события. Список полей — в [Данные события](/templates/logs#data) |
| `ts` | [DateTime](./datetime) | Когда событие произошло |

## Пример { #example }

```template
{% if event.viaJoinRequest %}Твоя заявка одобрена — добро пожаловать!{% else %}Привет, {{ member.name }}!{% endif %}
{% if event.inviteLinkName %}Ты пришел по ссылке «{{ event.inviteLinkName }}».{% endif %}
```
