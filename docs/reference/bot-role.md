# BotRole

<p class="lead">Роль бота. Роли создаются в разделе панели «Роли бота» и живут внутри бота. Роли участника — в <code>member.roles</code>, роль по ID — <code>chat.getRole(id)</code>.</p>

При выводе `{{ role }}` печатаются эмодзи и название роли.

## Свойства { #properties }

| Свойство | Тип | Описание |
|---|---|---|
| `id` | Строка | ID роли |
| `name` | Строка | Название |
| `color` | Строка | Цвет |
| `emoji` | Строка | Эмодзи роли |
| `priority` | Число | Приоритет: чем выше, тем главнее роль. Псевдоним — `position` |
| `isModerator` | Логический | Роль дает права модератора в боте |
| `isImmune` | Логический | Иммунитет к автомодерации |
| `xpMultiplier` | Число | Множитель опыта |
| `mention` | Строка | Эмодзи и название |

У ролей бота нет прав Telegram, поэтому `hasPermission` недоступен.

## Пример { #example }

```template
Твои роли: {% for r in member.roles %}{{ r }}{{ loop.last ? '' : ', ' }}{% else %}пока нет{% endfor %}
```
