# Arguments

<p class="lead">Аргументы вызова пользовательской команды — все, что написали после команды. Доступны как <code>arguments</code> в действиях пользовательских команд. Руководство — в статье <a href="/commands/arguments">Аргументы команды</a>.</p>

## Свойства { #properties }

| Свойство | Тип | Описание |
|---|---|---|
| `value` | Строка | Все аргументы одной строкой |
| `args` | Список строк | Аргументы, разделенные пробелами |
| `targetMember` | [Member](./member) | Участник, к которому обращена команда: на чье сообщение ответили, кого упомянули ссылкой, чей числовой ID или известный боту `@username` указали |
| `duration` | Число | Срок в миллисекундах из первого аргумента, похожего на срок: `1ч30м`, `2d` <Badge type="tip" text="новое" /> |
| `reason` | Строка | Остаток строки — причина <Badge type="tip" text="новое" /> |

## Методы { #methods }

Номера аргументов начинаются с 1.

| Метод | Возвращает | Описание |
|---|---|---|
| `get(n)` | Строка | Аргумент номер `n` |
| `after(n)` | Строка | Все аргументы, начиная с `n`-го включительно |
| `before(n)` | Строка | Все аргументы от первого до `n`-го включительно |
| `range(a, b)` | Строка | Аргументы с `a`-го по `b`-й |
| `getOption(имя)`, `getOptionsByType(тип)` | — | Всегда пусто: в Telegram нет параметров slash-команд |

## Форматы срока { #duration-format }

| Единица | Английский | Русский |
|---|---|---|
| Секунды | `30s` | — |
| Минуты | `10m` | `10м` |
| Часы | `2h` | `2ч` |
| Дни | `1d` | `1д` |
| Недели | `1w` | `1нед` |
| Месяцы | `1mo` | `1мес` |
| Годы | `1y` | — |

Единицы можно сочетать: `1ч30м`, `1d12h`.

## Пример { #example }

```template
{% set t = arguments.targetMember %}
{% require t returning 'Кого?' %}
{{ t }}: {{ arguments.duration ? duration(arguments.duration) : 'навсегда' }}, причина — {{ arguments.reason ?: 'не указана' }}
```
