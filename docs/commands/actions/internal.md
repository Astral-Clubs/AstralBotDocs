# Встроенная команда

<p class="lead">Действие вызывает одну из встроенных команд бота — <code>/mute</code>, <code>/warn</code>, <code>/rank</code> и другие — с аргументами, которые вы соберете шаблоном. Так можно дать встроенной команде свое название или сделать «быструю» версию с готовыми настройками.</p>

## Как это работает { #how }

Шаблон действия должен дать одну строку: **название встроенной команды и ее аргументы** — так, как их написал бы модератор в чате, только без префикса.

```template
mute {{ arguments.value }}
```

Когда участник напишет `!заткнуть @ivan 1ч флуд`, бот выполнит `mute @ivan 1ч флуд` — как будто модератор вызвал `/mute` сам. Ответит тоже встроенная команда, своим обычным текстом.

`arguments.value` — все, что участник написал после команды, одной строкой. Подробнее — в статье [Аргументы команды](../arguments).

## Права проверяются дважды { #permissions }

Бот проверяет права и у пользовательской команды, и у встроенной. Если хелпер может вызвать `!заткнуть`, но не имеет доступа к `/mute`, мьюта не будет.

::: warning Это защита, а не ошибка
Двойная проверка не дает обойти права встроенных команд через пользовательские. Чтобы хелперы могли мьютить, дайте им доступ к `/mute` в разделе **«Модерация»**.
:::

## Примеры { #examples }

**Мьют на час одной командой.** Команда `!тихо`, модератор отвечает ею на сообщение нарушителя:

```template
mute 1ч {{ arguments.value ?: 'Флуд' }}
```

Если модератор не указал причину, бот подставит «Флуд». Цель команды — участник, на чье сообщение ответили, как у обычного `/mute`.

**Свое название для рейтинга.** Команда `!я` показывает карточку уровня:

```template
rank
```

**Предупреждение с готовой причиной.** Команда `!реклама`:

```template
warn Реклама в чате
```

## Какие команды можно вызвать { #commands }

Любую встроенную команду из каталога: модерация (`warn`, `mute`, `ban`, `kick`, `purge`, `del`, `pin`…), уровни (`rank`, `top`), общие (`help`, `id`, `info`). Полный список с аргументами — в каталоге команд на сайте бота.
