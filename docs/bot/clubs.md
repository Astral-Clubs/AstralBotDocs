# Команда /clubs

<p class="lead">Команда <code>/clubs</code> показывает клубы семьи Astral, участников клуба и историю вступлений и выходов за последние 48 часов. Она работает только в группах, которые прошли <a href="./verification">верификацию</a>.</p>

## Где работает команда { #where }

- В группе с доступом: команда есть в меню группы и отвечает списком клубов.
- В группе без доступа: бот отвечает короткой подсказкой со ссылкой на заявку. Подсказка приходит не чаще раза в 6 часов на группу, в остальное время бот молчит.
- В личных сообщениях: команды нет в меню, а на вызов бот отвечает, что `/clubs` работает только в верифицированных группах.

## Что показывает команда { #what }

| Экран | Что на нем |
|---|---|
| Список клубов | По 10 клубов на странице. Клуб `#80RQUGCV9` закреплен над списком. Страницы листаются кнопками |
| Клуб | Кубки клуба, число участников, место в локальном и мировом рейтинге, минимум кубков для вступления, участники по 30 на странице |
| История | События вступления и выхода за 48 часов, по 15 на странице. Открывается кнопкой **«История»** на экране клуба |

На экране клуба также есть кнопка **«Статистика»**: она открывает страницу статистики в панели.

## Кнопки { #buttons }

Кнопки под сообщением может нажимать только тот, кто вызвал команду. Остальным бот отвечает, что кнопкой может пользоваться только инициатор. Через 5 минут кнопки пропадают: чтобы продолжить, вызовите `/clubs` снова.

## Ссылки на Telegram { #links }

Показывать ли ссылки на Telegram-аккаунты игроков, определяет второй флажок верификации.

| Доступ группы | Участники клуба | Президент в списке клубов |
|---|---|---|
| Только `/clubs` | Имя жирным текстом, без ссылки | Игровой ник или «—», юзернейм не показывается |
| `/clubs` и юзернеймы | Имя игрока со ссылкой на Telegram, если аккаунт привязан | Ссылка `@юзернейм` или «Неизвестно» |

Подробнее о флажках — на странице [Верификация группы](./verification#access).
