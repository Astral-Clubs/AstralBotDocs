# Турниры

<p class="lead">Зарегистрироваться на турнир Astral можно в личных сообщениях с ботом. Верификация группы для этого не нужна.</p>

## Как зарегистрироваться { #register }

1. Откройте личные сообщения с ботом и отправьте `/tournaments`. Бот покажет турниры с открытой регистрацией: формат, тип сетки и кому открыт турнир.
2. Нажмите кнопку нужного турнира.
3. Отправьте свой игровой тег, например `#ABC123`.
4. Бот покажет имя, кубки и клуб найденного игрока и спросит, вы ли это. Нажмите **«Да, это я»**.
5. Если турнир командный, бот спросит, создать команду или вступить по коду. Отправьте название новой команды или код существующей.
6. Бот сообщит, что вы зарегистрированы.

Если тег не найден, бот попросит отправить его еще раз.

В группе регистрация недоступна: бот предложит написать ему в личные сообщения и снова нажать `/tournaments`.

## Форматы и доступ { #formats }

| Что указано в списке | Варианты |
|---|---|
| Формат | 1 на 1, 2 на 2, 3 на 3 |
| Сетка | на выбывание, двойное выбывание, швейцарка, круговой |
| Кому открыт | открыт всем или только клубы Astral |

В турнир «только клубы Astral» игрок вступает, если состоит в одном из клубов семьи.

## Как отменить регистрацию { #cancel }

Команда `/cancel` в личных сообщениях отменяет текущее действие: бот забудет введенный тег и шаг регистрации. Кнопка **«Нет»** на подтверждении тега отменяет регистрацию тоже.

Если сессия простояла слишком долго, бот ответит, что она истекла. Начните заново с `/tournaments`.

## Частые ошибки { #errors }

| Что ответил бот | Что делать |
|---|---|
| Сейчас нет турниров с открытой регистрацией | Дождитесь анонса следующего турнира |
| Этот турнир только для игроков из клубов семьи Astral | Вступите в один из клубов Astral и повторите регистрацию |
| Вы уже зарегистрированы на этот турнир | Ничего: регистрация уже есть |
| Регистрация на этот турнир закрыта | Регистрация закончилась |
| Турнир уже набрал полный состав участников | Мест больше нет |
| Команда с таким кодом не найдена | Проверьте код и отправьте еще раз |
| В этой команде уже нет свободных мест | Создайте свою команду или попросите другой код |
