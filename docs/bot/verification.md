# Верификация группы

<p class="lead">Команда <code>/clubs</code> и данные Astral в шаблонах доступны только верифицированным группам. Владелец группы подает заявку в панели одной кнопкой, решение принимает владелец платформы.</p>

## Что дает верификация { #access }

Доступ складывается из двух флажков. Их выдает владелец платформы при одобрении заявки.

| Доступ | Что открыто |
|---|---|
| Нет доступа | Ничего: ни `/clubs`, ни `astral` в шаблонах. Так у каждой группы по умолчанию |
| Команда `/clubs` и данные Astral | [Команда `/clubs`](./clubs) без ссылок на Telegram и [пространство `astral`](../templates/astral) в шаблонах без связи игроков с Telegram |
| Плюс юзернеймы игроков | Ссылки на Telegram в `/clubs` и свойства `member.astral` в шаблонах |

Флажок юзернеймов не выдается без первого.

Привязка группы к клубу Astral доступа не дает: заявку подают и такие группы. Прошлое использование `/clubs` доступ тоже не сохраняет.

## Кто может подать заявку { #who }

Только владелец группы. Бот проверяет это в момент подачи, по актуальным данным Telegram. Анонимный владелец тоже подходит.

Условия:

- Бот состоит в группе.
- У группы нет другой активной заявки.
- Если заявку отклонили, новую можно подать через 7 дней. Владелец платформы может разрешить раньше.

## Как подать заявку { #apply }

1. Добавьте бота в группу.
2. Откройте страницу **«Верификация»** в панели. Ссылка на нее есть в подсказке бота на `/clubs`, а команда `/verify` в группе присылает кнопку на эту страницу.
3. Войдите через Telegram.
4. Выберите группу и нажмите **«Отправить заявку»**. Заполнять ничего не нужно.

Ответ придет в Telegram: заявителю в личные сообщения, а если они закрыты, то в группу.

Если группы нет в списке, добавьте в нее бота и проверьте, что вы ее владелец. Команда `/verify` работает только у владельца, остальным бот отвечает, что заявку подает только владелец группы.

## Статусы заявки { #statuses }

| Статус на странице | Что значит |
|---|---|
| Не подана | Заявки нет, ее можно отправить |
| На рассмотрении | Заявка у владельца платформы, ответ придет в Telegram |
| Одобрена | Указано, что открыто: `/clubs` и, если выдано, юзернеймы |
| Отклонена | Указаны причина и дата, с которой можно подать заявку снова |

## Что происходит после решения { #after }

Одобрение сразу добавляет `/clubs` в меню команд группы. Доступ принадлежит группе: смена владельца, выход бота и его возвращение доступ не снимают.

Владелец платформы может позже изменить доступ или отозвать его. Тогда `/clubs` исчезает из меню, а шаблоны, которые читают данные Astral, начинают возвращать ошибку.

## Как проверить доступ в шаблоне { #template }

Свойство `astral.access` возвращает `clubs` и `usernames`, поэтому шаблон может проверить доступ заранее:

```template
{% if astral.access.clubs %}
Клубов в базе: {{ astral.clubs() | length }}
{% else %}
Эта группа еще не верифицирована.
{% endif %}
```

Подробнее об ошибках и уровнях — на странице [Пространство astral](../templates/astral#access).
